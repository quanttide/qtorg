# 联盟页面

## 功能定位

展示量潮联盟组织信息，包括成员单位、合作模式、治理结构。

## 页面结构

- **联盟简介**：定位、使命、愿景
- **成员单位**：成员列表与简介
- **合作模式**：合作方式、权益说明
- **治理结构**：决策机制、议事规则

## 数据来源

- 数据目录：`data/profile/qtalliance/`
- 主要文件：`index.md`、`structure/`、`institution/`

## 技术方案

- 数据读取：Markdown 文件解析
- 页面渲染：静态生成
- 组件：组织结构树（复用 qttech 组件）

## 优先级

P1，二期实现。
