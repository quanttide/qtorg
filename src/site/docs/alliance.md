# 联盟页面

## 功能定位

展示量潮创新联盟组织信息，包括成员单位、合作模式、治理结构。

## 页面结构

- **联盟简介**：定位（盟友生态的组织载体）、核心目标（让盟友被看见）
- **成员单位**：盟友目录化（企业、开发者、学者、执行方）
- **合作模式**：信用背书、生态凝聚
- **治理结构**：三大机构（联盟理事会、联盟代表大会、联盟秘书处）

## 数据来源

- 数据目录：`data/profile/qtalliance/`
- 主要文件：
  - `index.md`：组织定位、核心目标、组织形态
  - `structure.md`：组织结构（三大机构）
  - `institution.md`：制度体系
  - `culture.md`：文化特质

## 技术方案

- 数据读取：Markdown 文件解析
- 页面渲染：静态生成
- 组件：盟友列表、治理结构图

P1，二期实现。
