# 公司页面

## 功能定位

展示量潮科技组织信息，包括治理架构、部门设置、职级体系。

## 页面结构

- **公司简介**：定位、业务板块
- **治理架构**：两院制（上议院/下议院）、矩阵式架构
- **部门设置**：秘书处、事业部、共享中心、顾问团（组织结构树）
- **职级体系**：五序列（G/P/F/T/M）职级与晋升规则

## 数据来源

- 数据目录：`data/profile/qttech/`
- 主要文件：`index.md`、`structure/`、`institution/`

## 技术方案

- 数据读取：Markdown 文件解析
- 页面渲染：静态生成
- 组件：组织结构树、职级表、部门卡片

## 优先级

P0，首期实现。
