# 实训基地页面

## 功能定位

展示量潮实训基地组织信息，包括部门设置、职级体系、参与方式。

## 页面结构

- **基地简介**：定位、核心目标
- **部门设置**：职能部门（技术/产品/市场/综合）、管理部门（秘书处）
- **职级体系**：L-3/L-2/L-1/L0/L1+ 职级与晋升路径
- **参与方式**：准入流程、考核机制

## 数据来源

- 数据目录：`data/profile/qtacademy/`
- 主要文件：`index.md`、`structure/`、`institution/`

## 技术方案

- 数据读取：Markdown 文件解析
- 页面渲染：静态生成
- 组件：组织结构树、职级表、部门卡片

## 优先级

P0，首期实现。
